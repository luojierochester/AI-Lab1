# SFML 操作录屏

[sfml-playback-demo.mp4](sfml-playback-demo.mp4) 为课程第 10 题十五数码的实际操作录屏，时长 20 秒，1120 × 800、30 帧/秒，H.264 编码，无配乐和旁白。

| 时间 | 操作 |
| --- | --- |
| 0–13 秒 | 自动播放，然后暂停 |
| 13–15.5 秒 | 下一步：第 21 步到第 22 步 |
| 15.5–18 秒 | 上一步：第 22 步回到第 21 步 |
| 18–20 秒 | 跳到终点：显示第 70 步的终点局面 |

视频已嵌入课程汇报 PPT 第 14 页，放映到这一页后，单击或按空格即可播放；复制 PPT 到其他电脑时，无需依赖本文件的路径。独立 MP4 可作为播放备用文件。

录制使用仓库内的 SFML 程序和 `visualizer/examples/15puzzle-case10-70steps.npz`。后期只剪掉操作之间的静止等待，并加上操作提示；滑块动画保持原速。这是解路径播放演示，20 秒不是求解耗时。
